# Mentor–Mentee Management System

This project digitizes the traditional offline mentor–mentee record system
used in colleges by providing a role-based desktop application.

##  Objective
To allow students to submit academic and activity data digitally, which is
verified and approved by their assigned mentor.

##  Roles
### Student
- Login securely
- Complete personal profile (one-time)
- Submit attendance and marks
- View submission status (Pending / Approved)

### Mentor
- Login securely
- View only assigned students
- See overall verification status
- Review personal, attendance, and marks data
- Approve pending submissions

### Admin (future scope)
- Manage users
- Assign mentors
- System overview

## 🛠️ Tech Stack
- Python
- Tkinter (GUI)
- SQLite (Database)
